# Easy Task: Mathematical Operations

## Objective
Identify and fix defects in math.py.

Preserve all existing function names and parameters.

## Functional Requirements

1. addition(a, b) must return the sum of two numbers.

2. subtraction(a, b) must return the difference
   between two numbers.

3. multiplication(a, b) must return the product
   of two numbers.

4. division(a, b) must return the quotient
   of two numbers.

5. Division by zero must raise ValueError.

6. Functions must work with:
   - Positive numbers
   - Negative numbers
   - Zero
   - Decimal numbers

## Constraints

- Preserve existing function names.
- Preserve existing parameters.
- Do not modify TASK.md.
